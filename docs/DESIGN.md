# Clawgotchi Web UI Design System

This document describes the OpenClaw-inspired visual language applied to the web interface.

## Design Direction

- Dark-first, high-contrast UI with minimal chrome and technical terminal aesthetics.
- Section structure with `⟩` prefixed headings.
- Grid-based cards for features, runtime status, and management screens.
- Monospace-forward code blocks with copy-to-clipboard interaction.

## Core Tokens

Defined in `/Users/lukaswaschul/Desktop/Clawgotchi/app/presentation/static/styles.css`.

- `--bg`: base background
- `--fg`: primary text
- `--muted`: secondary text
- `--border`: divider and control border
- `--card`: elevated surface
- `--accent`: primary call-to-action color
- `--accent-contrast`: text color on accent surfaces

Supporting tokens include `--bg-soft`, `--surface-2`, `--info`, `--warning`, `--danger`, `--success`, `--radius`, and `--shadow`.

## Typography

- Base font stack: `system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif`
- Code stack: `ui-monospace, SFMono-Regular, Menlo, Monaco, Consolas, "Liberation Mono", "Courier New", monospace`

## Components

Macros are defined in `/Users/lukaswaschul/Desktop/Clawgotchi/app/presentation/templates/components.html`.

- `section_header(title, subtitle="", anchor_id="")`
- `code_block(code, label="Terminal")`
- `feature_card(title, description, cta_label="", cta_href="#")`
- `badge(text, tone="neutral")`
- `quote_card(quote, source)`

Reusable class components in CSS:

- Buttons: `.btn`, `.btn-primary`, `.btn-ghost`
- Pills/Badges: `.pill`, `.pill-accent`, `.pill-danger`
- Cards and grids: `.feature-card`, `.feature-grid`, `.quote-card`, `.readout-card`, `.command-card`
- Headings: `.section-heading` with `⟩` prefix generated by macro
- Code UI: `.code-block`, `.btn-copy`, `.copy-success`

## Usage Examples

```jinja2
{% from "components.html" import section_header, code_block, feature_card, badge %}

{{ section_header("Quick Start", "Bootstrap from terminal", "quick-start") }}
{{ code_block("$ ./install.sh\n$ sudo systemctl enable --now clawgotchi.service", "Bootstrap Commands") }}

<div class="feature-grid">
  {{ feature_card("Plugins", "Enable runtime skills.", "Open", "/plugins") }}
  {{ feature_card("Themes", "Switch visual packs.", "Open", "/themes") }}
</div>

<div class="pill-row">
  {{ badge("FastAPI", "accent") }}
  {{ badge("Jinja2 UI") }}
</div>
```

## Extension Guidelines

- Keep new views token-driven. Do not hardcode hex colors in templates.
- Use the component macros first, then add page-specific utility classes only when needed.
- Prefer card grids for new plugin/theme/integration modules.
- Reuse `.pill-row` and `.feature-grid` patterns for future plugin metadata panels.
- For new CLI snippets, always use `code_block(...)` to keep copy behavior consistent.
